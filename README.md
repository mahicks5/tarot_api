# Tarot API

### Description
A RESTful Tarot card API built with Spring Boot.

### Some Domain Notes
A tarot deck has:
- 22 Major Arcana cards (The Fool, The Magician, etc.). No Suit and numbered 0-21
- 56 Minor Arcana Cards. Split across 4 suits (Wands, Cups, Swords, Pentacles), numbered 1-14 (Ace through King)
